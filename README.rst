Foundational Review Series Templates
====================================

**Templates to be used for submission to FQxI's Foundational Review Series. Currently there are two templates: one designed in LaTeX, and the other made in Microsoft Word.**

Directories
-----------

There are two directories in this repository:

* ``LaTeX formatting files/``: This directory contains all of the necessary files to compile a LaTeX version of the FQxI FRS template. The ``fqxi_template.tex`` script is commented and has basic commands (formatting, citation, and custom commands) demonstrated. It was compiled in `Overleaf <https://www.overleaf.com/>`_, but should be compatabile with local version of LaTeX (e.g., MiKTeX, TeX Live, and MacTeX).

* ``Microsoft Word Template/``: This contains the ``.docx`` file of the Word template. Similar to the LaTeX directory, all of the necessary instructions for formatting are in the file itself. This template was made with `Google docs <https://docs.google.com/>`_. Since there are differences between Google docs and traditional Microsoft Word, we have included instructions for both distributions. 


Other files within the repository
---------------------------------

* ``FQxI_Foundational_Review_Series_Publication_Guidelines.pdf``: This is the official publication guidelines for FQxI's Foundational Review Series. It contains all of the formatting and submission requirements for a successful submission to the series. We recommend reading through this document before begining a draft in either template, as it will give you a good idea of what is expected in terms in terms of the code of conduct and terms and conditions, authorship, FRS scope and editorial criteria, formatting, submission process, and  peer-review process.

* ``FQxI Foundational Review Series Frequently Asked Questions.pdf``: This document contains answers to frequently asked questions about the FQxI Foundational Review Series. It is a good resource to consult if you have any questions about the series that are not answered in the publication guidelines.

* ``README.rst``: This is the default readme file for this repository. It contains a brief description of the repository and its contents, as well as instructions for how to get in touch or get involved.
